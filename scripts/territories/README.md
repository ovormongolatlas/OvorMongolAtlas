# Territory and border data for the Timeline Map

These scripts turn period maps into the JSON files in `src/data/`. Each script's
header names its source map, how it was georeferenced, and its error. The scans
themselves are not kept in the repository; each script says which file it expects.

| Script | Writes |
| --- | --- |
| `trace_korostovets.py` | `korostovets-1914-*.json` (Korostovets, Map of Mongolia, about 1914) |
| `period_outlines.py` | `period-outlines.json`: Qing outline, borders with Russia and Tuva |
| `extend_amur.py` | extends `russiaManchuria` in `period-outlines.json` east of Blagoveshchensk (AoifeIves, Map 1) |
| `trace_nc_1935_1940.py` | Narangoa and Cribb's 1935–1940 map, traced |
| `trace_jp_mengjiang.py` | South Chahar and North Shansi from 蒙疆地域圖 |
| `fit_nakamura.py`, `trace_great_wall.py`, `dariganga_claim.py` | Nakamura (1941) redraw: Great Wall, Dariganga loop |
| `combine_territories.py` | `territories.json`: mmg1936, mlaagRuled, mlaagClaimed, scag, nsag, mengjiang1939, manchukuo, mengjiangClaimed1940 |
| `outer_mongolia.py` | an earlier version of `outer-mongolia.json` (Korostovets-based MPR outlines) |
| `trace_kyakhta_readings.py` | the two readings of the 1915 Kyakhta frontier (AoifeIves, Map 2) |
| `alashan_river.py` | closes the `alashan` ring in `territories.json` up to the Yellow River |
| `refit_to_korostovets.py` | puts the MPR outline back on Korostovets's line (checked against Nakamura 1941 and the 1934 Manchukuo map) and refits every neighbour to it; writes `outer-mongolia.json` (`base`, `held1935`, `mpr1942`, `nomonhan`, `barga1912`, `dariganga`) and updates `territories.json` |
| `manchukuo_coast.py` | carries the Manchukuo rings out to the coast and the Yalu, minus Korea and the Kwantung Leased Territory (`kwantung-1934-line.json`, from the 1934 Manchukuo map) |

| `trace_banner_map_1930s.py` | Outer Mongolia's frontier with the Inner Mongolian banners and the Dariganga district from the 1930s English banner map (`frontier-1930s.json`), used by `refit_to_korostovets.py` |
| `qing_uriankhai.py` | adds Uriankhai (Tuva) to the Qing outline in `period-outlines.json` |
| `korea_kwantung.py` | `territories.json`: `korea`, `koreaNorth`, `koreaSouth` (Yalu and Tumen rivers; 38th parallel) and `kwantung` |
| `trace_chahar_postal_atlas.py` | Chahar's provincial boundaries from the China Postal Atlas sheet into `chahar-postal-atlas-lines.json`; not used on the map at present (taken off pending a check) |
| `bogd_1913.py` | `territories.json`: `bogd1913`, the Shilingol and Ulaanchab leagues (Nakamura league lines) held for the Bogd Khanate in 1913 |
| `council_1934.py` | `territories.json`: `council1934`, `council1935`, the Mongolian Political Affairs Council's four leagues (Nakamura league lines: Shilingol, Ulaanchab, Chahar, Yikezhao), minus Manchukuo for each year |
| `postwar_1945_46.py` | `territories.json`: `impr1945` (Shilingol and Chahar leagues, Nakamura) and `empag1946` (Jirim, Juu Uda and Josotu banner lands from the 1930s English banner map, plus Hulunbuir), for the two short-lived Mongol governments of 1945–1946 |
| `atwood_2002_lines.py` | `atwood-2002-lines.json` (copied to `src/data/`): the 1925–1928 boundaries of the Chahar, Suiyuan and Rehe special administrative districts and Atwood's MPR frontier near Üde (Map 11.1), and his 1928 Hulun Buir–MPR frontier (Map 21.1), from Atwood, *Young Mongols and Vigilantes* (2002) |
| `shilingol_frontier.py` | `outer-mongolia.json` and `territories.json`: Shilingol's frontier with Outer Mongolia in the Üjümüchin sector on Nakamura's line (agreeing with Atwood's Map i.1 and the 1962 treaty line), and the eastern Shilingol band taken out of Manchukuo, Jehol 1932 and the 1946 East Mongolian outline; run after `postwar_1945_46.py` |
| `china_and_neighbours.py` | `territories.json`: the Republic of China for each period (`roc1912` … `roc1946`, including `roc1934`), `eastHebei` (from `east-hebei-1935-40.json`); `period-outlines.json`: `jeholFengtian` (not drawn at present). `northChina1938` and `northChina1940` (the provinces under the Japanese-sponsored governments, bounded by Mengjiang, Manchukuo, the Shanxi–Shaanxi stretch of the Yellow River and the coast) |


Order: `refit_to_korostovets.py`, `manchukuo_coast.py`, `korea_kwantung.py`, `bogd_1913.py`, `council_1934.py`, `postwar_1945_46.py`, `shilingol_frontier.py`, `china_and_neighbours.py`. (`china_and_neighbours.py` was last run before `shilingol_frontier.py`; rerunning it would need the strip and band carried into the Republic's rings again.)

## Outputs whose working scripts were not kept

The following were made in October 2026 with working scripts that were lost when
the workspace they ran in was reset. The method and sources for each are written
in the area's `note` and `source` in `src/data/map-boundaries.ts`, which is the
record to check them against; they should be regenerated by a kept script when
next revised.

- `aoife-outer-mongolia.json`: the AoifeIves-based Outer Mongolian outlines (`claim`,
  `held1935`, `mpr1942`, `nomonhan`) and `barga1912`, input to `refit_to_korostovets.py`.
- `pre-refit-territories.json`, rings `mmg1937`, `manchukuo1932`, `jehol1932`,
  `manchukuo1942`, `manchukuo` and `alashan` (the last before `alashan_river.py`), input to
  `refit_to_korostovets.py`.
